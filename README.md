# Clover website
Open index.html in a browser after extracting the ZIP. No dependencies or internet connection required for the storefront.

The site uses original images cropped from the supplied wireframes; the homepage uses the supplied complete hero artwork with a linked Shop Now area. All twelve original wireframes are included, with the latest uploaded versions replacing earlier copies. The layout is a responsive single-page implementation.

Product prices for candles, flowers, mugs and cards match the supplied designs. Gift box prices are indicative £25/£35, since custom prices are unspecified. Photo selection is local only. The shopping bag is stored locally in the browser. Checkout and contact are previews only; no payment, order submission, email, image upload or delivery integration is connected. Delivery and returns terms require business confirmation.
